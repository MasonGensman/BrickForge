# Brick-Forge
An open-source LEGO design companion for planning, validating, and creating custom LEGO models with seamless BrickLink Studio workflows. # BrickForge

> **Design Better LEGO Creations.**

BrickForge is an open-source companion to BrickLink Studio that helps builders plan, validate, and manage custom LEGO creations.

## Vision

BrickForge is designed to complement—not replace—BrickLink Studio.

It focuses on:

- Project management
- Reference photo organization
- LEGO model planning
- Validation
- Export tools
- Future AI-assisted design workflows
