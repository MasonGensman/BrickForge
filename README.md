# StudWorks

> **Design Better LEGO Creations.**

StudWorks is an open-source companion to BrickLink Studio that helps builders plan, validate, and manage custom LEGO creations.

## Vision

StudWorks is designed to complement—not replace—BrickLink Studio.

It focuses on:

- Project management
- Reference photo organization
- LEGO model planning
- Validation
- Export tools
- Future AI-assisted design workflows
